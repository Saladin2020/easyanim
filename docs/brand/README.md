# Easy Suite brand assets

Generated by the Easy Suite brand script (pixel logos, banners, social previews). Same frame, palette and
fonts across all thirteen tools; only the icon and accent colour change. Easy Anim uses indigo `#5d6ee8` and an icon of
storyboard panels crossed by a timeline playhead; its banner and social art are an Easy Anim render of
`raya_open_house` with the built-in placeholder characters (no Easy Sprite / LPC art).

| File | Use |
|---|---|
| `banner-anim.png` (1280×320) | README header |
| `social-anim.png` (1280×640) | GitHub social preview: Settings → General → Social preview → Upload |
| `logo-anim.png` (240×240), `logo-*-96.png` | Tool logos; the `-96` set is used by the suite table |

Fonts in the art: Press Start 2P and Kanit (both SIL OFL 1.1). v2 style: subtle green accent and a light
8-point star (girih) pattern on the teak, cream and gold palette.
